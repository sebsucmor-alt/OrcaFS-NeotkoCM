What this is

Snapmaker Orca with a lot of extra features, built by one person who designs in 3D and reads code, rather than the other way round. Most of them started as "why can no slicer do this?". There is no roadmap; things get built when they get interesting.

Everything is opt-in. Leave the new settings alone and the build slices like stock Snapmaker Orca. Every release gets checked against that.

The tour is also honest about how finished each thing is. Some of it is print-verified, some of it is shipped, and a few things have never been printed at all. Each page says which, and so does the feature map.
