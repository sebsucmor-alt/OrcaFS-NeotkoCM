V2 · COLORSTITCH

Per-line gradients, not painted layers

A ColorStitch pass picks the filament for each fill line: smooth dithered blends (2–3 colours), exact manual stripes, or a custom typed pattern — all on the top surface only.
Must-know: set Quality → Top surface pattern → Monotonic Line, or complex tops mis-sequence. Fragmented stripes across holes? Switch Line distribution to LaneQuant.

V3 · PATHBLEND

A Z-thickness ramp, not a color switch

One filament climbs as a physical ramp inside the layer; in Full mode a second one caps the rest. The visible gradient is optical — thickness vs the filament's TD, not a mixed color.
Must-know: the gradient runs along the build-plate Y axis — rotate the object to aim it. The ADV… editor adds flat start/end zones and a full-opacity “techo”.

V4 · MULTIPASS

Stacking Solid passes — cross-hatch & glaze

There is no MultiPass button anymore: stack 2–3 Solid passes, give each its own tool, angle and Z share, and you get cross-hatch, glazes and optical blends.
Must-know: aim for the Z shares to add up to the full layer height. Perimeter override clones the walls into every Solid pass so the rim matches each glaze.

V5 · PAINTER

Paint each top — not the whole object

Save Sandwiches as profiles and flood-fill them onto individual top faces with the ColorStitch Painter. Different steps of one object can carry different recipes — bottoms too.
Must-know: painted objects are all-or-nothing — unpainted areas get no effect, not the preset. Profiles and paint travel inside the 3MF.

V6 · FINALE

All together — one print, every technique

One staircase object: ColorStitch, MultiPass and PathBlend on separate tops, repainted live, previewed with RealColor and proven against real prints.
Must-know: RealColor is a TD-based optical approximation, not a guarantee. Any Sandwich scene auto-promotes the wipe tower to NeoTower to keep purges in sync.

V7 · TUTORIAL

How to paint a Sandwich — real app

Seven real clicks in the actual UI: open the Painter, grab a Generator blend, click a top, refine it in Pro, stack sub-passes, switch effects, save the recipe.
Must-know: press M to open the Painter. TD scale: 0.1–0.5 opaque · 3+ translucent — the Result swatch predicts the printed colour before slicing.
