V1 · PITCH

Why I forked Orca

The core idea of the pack. The Top and Penultimate layers stop being one flat fill. You build them as a small stack of passes yourself, choosing Solid, ColorStitch or PathBlend for each one.
Where: Quality → Surface ColorStitch → Sandwich editor… Drag the dividers to split the layer height between passes.

V2 · COLORSTITCH

Colour, chosen line by line

A ColorStitch pass picks the filament for every fill line. You can set smooth dithered blends of two or three colours, exact manual stripes, or a pattern you type by hand. It only touches the top surface.
Must-know: set Quality → Top surface pattern → Monotonic Line, or complex tops come out mis-sequenced. If stripes fragment across holes, switch Line distribution to LaneQuant.

V3 · PATHBLEND

A ramp of real thickness

One filament climbs as a physical ramp inside the layer, and in Full mode a second one caps the rest. The gradient you see is optical. It comes from the ramp's changing thickness seen through the filament's TD, so no colour is ever mixed.
Must-know: the gradient runs along the build-plate Y axis, so rotate the object to aim it. The ADV… editor adds flat start and end zones, plus a full-opacity "techo".

V4 · MULTIPASS

Stacking Solid passes for cross-hatch and glaze

There is no MultiPass button any more. Stack two or three Solid passes, give each one its own tool, angle and Z share, and you get cross-hatch, glazes and optical blends.
Must-know: the Z shares should add up to the full layer height. Perimeter override clones the walls into every Solid pass, so the rim matches each glaze.

V5 · PAINTER

Paint each top face on its own

Save Sandwiches as profiles, then flood-fill them onto individual top faces with the ColorStitch Painter. Different steps of one object can each hold a different recipe, and bottom faces work too.
Must-know: painted objects are all-or-nothing. Any area you leave unpainted prints with no effect at all, and the preset is ignored. Profiles and paint both save inside the 3MF.

V6 · FINALE

Everything on one print

One staircase object carries ColorStitch, MultiPass and PathBlend on separate top faces. Repaint them live, preview the result with RealColor, then check it against the real prints.
Must-know: RealColor gives a TD-based optical preview of the final colour, so read it as a guide. Any Sandwich scene moves the wipe tower to NeoTower on its own, to keep the purges in sync.

V7 · TUTORIAL

How to paint a Sandwich, step by step

Seven real clicks in the actual app: open the Painter, grab a Generator blend, click a top face, refine it in Pro, stack sub-passes, switch effects, and save the recipe.
Must-know: press M to open the Painter. On the TD scale, 0.1–0.5 is opaque and 3 or more is translucent. The Result swatch predicts the printed colour before you slice.
